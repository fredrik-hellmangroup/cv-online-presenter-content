### Nordhemfastighetsmäkleri
**Period:** 2026 - pågående
**Roll:** Lead Fullstack-utvecklare (.NET / React)

Nordhem Fastighetsmäkleri är en premiuminriktad fastighetsförmedlare med starkt fokus på
digital kundupplevelse och teknikstöd för mäklarverksamhet.

Utvecklingen omfattar Nordhem Estate, en premium digital kundupplevelse för
fastighetsmäkleri i Växjöregionen med backenddrivna objekt, AI-driven concierge,
mäklarprofiler samt flöden för intresseanmälan och visningsförfrågningar. Uppdraget innebär
ansvar för arkitektur och fullstackutveckling över både frontend och backend, inklusive
integration mot Vitec för synkronisering av objekt- och mäklardata.

- Arkitektur och fullstackutveckling av backend i ASP.NET Core Web API med SQL Server
och Entity Framework Core.
- Utveckling av frontend i React och TypeScript med fokus på premiumkundupplevelse.
- Integration mot Vitec för synkronisering av objekt- och mäklardata.
- Arbete med testbarhet, deployments och stabila informationsflöden mellan kundytor,
API:er och externa tjänster.
- Användning av AI-assisterade arbetsflöden via Claude-agenter för analys och
implementation.

#### Resultat
Lösningen stärker det digitala kundmötet och ger verksamheten ett stabilt stöd för
aktuell objektsdata, lead capture och premiumexponering av objekt och mäklarteam.

#### Nyckelord
React, TypeScript, Vite, Tailwind CSS, Google GenAI, ASP.NET Core, .NET, Entity Framework Core, SQL Server, Vitec API, Swagger, GitHub Actions, IIS, Claude Code, GitHub Copilot, JWT
